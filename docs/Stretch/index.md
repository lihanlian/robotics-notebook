# Stretch

Notes and projects using Stretch 3, including mobile-base control, navigation, and mobile manipulation.

The [Stretch-MPC-Tracking]({% link docs/Stretch/stretch-mpc-tracking.md %}) project connects [Navigation]({% link docs/Navigation/index.md %}) and [Control]({% link docs/Control/index.md %}) to practical robot experiments.

The [Stretch-PBVS-Grasping]({% link docs/Stretch/stretch-pbvs-grasping.md %}) project collects notes on position-based visual servoing for grasping with Stretch.
